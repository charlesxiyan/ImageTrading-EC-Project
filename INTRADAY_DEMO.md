# WRDS intraday demo

The current data standard and latest-basis historical price adjustment are documented in [README.md](README.md#current-intraday-data-standard). Use `adjust_bar_prices.py` for a separate CFACPR-adjusted price dataset; the raw data described here remain unchanged.

The downloader stores 5-minute bars for the historical union of S&P 500, NASDAQ 100, and DJIA 30. The verified adapter currently supports **2023-01-01 through 2023-06-30** only, covering 124 CRSP trading dates. All these sessions use the regular 09:30–16:00 US Eastern schedule. Other periods require session-calendar and source-schema validation, especially early closes.

## Run

```bash
python download_intraday_bars.py --limit-days 1
python download_intraday_bars.py
python download_intraday_bars.py --workers 2
python download_intraday_bars.py --workers 4
```

The defaults use the WRDS username in `WRDS_USERNAME` (else the local login name) and output directory `~/Market Data/demo_2023_h1`. Authentication is handled by the official WRDS client; credentials are not stored in project files. Required packages are `wrds`, `pandas`, and `pyarrow`.

Aggregation runs inside WRDS, with each query processing one trading date. Only aggregated bars are transferred to the local machine. No full raw trade/quote archives or image tensors are stored locally. Each successfully completed date is recorded in the manifest; rerunning verifies the file checksum and skips that date. A changed configuration or source mapping requires a new output directory once any date is complete.

The default uses one connection. `--workers` supports up to four independent dates concurrently through separate connections, in addition to the metadata connection; only the parent thread writes files and updates the manifest. Start conservatively and respect your WRDS connection/resource limits. Interrupted or failed runs can be resumed with the same command.

## Files

- `bars_5min/YYYY-MM-DD.parquet`: a complete 78-interval grid for every historical member, including explicitly missing intervals.
- `daily_universe.parquet`: membership by date/PERMNO, historical ticker, index memberships, and identifier status.
- `daily_tickers.json`: daily identifier lists. Consult the universe table's `identifier_status` before treating a ticker as actively traded.
- `daily_taq_mapping.parquet`: historical TAQ root/suffix mappings and mapping provenance.
- `crsp_daily_adjustment_factors.parquet`: separate CRSP daily price/share adjustment factors and daily price/volume references.
- `manifest.json`: exact configuration, source tables, inactive-name audit, per-date quality counts, file sizes, checksums, and completion status.
- `data_quality_summary.json`: post-download validation summary, generated by `validate_intraday_demo.py` after all dates complete.

`bar_start` and `bar_end` are timezone-aware timestamps in `America/New_York`; bars are left-labeled and cover half-open intervals. Thus 09:30 identifies [09:30,09:35). No return labels or train/validation/test splits are generated at this stage.

| Fields | Meaning |
| --- | --- |
| `date`, `bar_start`, `bar_end` | Trading date and explicit interval boundaries; complete bar information is available only after the interval ends. |
| `permno` | Stable CRSP security identifier; use this for grouping securities. |
| `ticker`, `indices` | Historical CRSP ticker and deduplicated index memberships. |
| `sym_root`, `sym_suffix` | Actual TAQ root and share-class suffix; do not infer share classes from ticker alone. |
| `identifier_status`, `mapping_source`, `match_lvl` | Historical identifier and mapping audit fields. |
| `open`, `high`, `low`, `close` | First, maximum, minimum, and last eligible raw trade prices within the interval. |
| `volume`, `trade_count`, `vwap` | Eligible share volume, eligible print count, and eligible volume-weighted average price. |
| `status` | `observed`, `no_eligible_trades`, or `no_symbol_mapping`. |

Read one day without loading the entire dataset:

```python
from pathlib import Path
import pandas as pd

root = Path.home()/'Market Data/demo_2023_h1'
bars = pd.read_parquet(root / 'bars_5min/2023-01-03.parquet')
aapl = bars.loc[bars['ticker'].eq('AAPL')]
print(aapl[['bar_start', 'open', 'high', 'low', 'close', 'volume', 'status']].head())
```

## Security identity

Membership uses CRSP S&P 500 history and Compustat index membership, with verified index headers for NASDAQ 100 and DJIA 30. Compustat securities map to PERMNO via date-effective CCM links.

The daily WRDS CRSP–TAQ link is supplemented by an exact match between date-effective CRSP NCUSIP and the first eight characters of CUSIP in the TAQ daily master. Existing links are cross-checked against master matches where both exist. Ambiguous or inconsistent mappings fail rather than guessing a ticker. Daily master `symbol_15` separates root and class suffix with whitespace; that format was verified against BRK B and simple symbols in the actual source. `mapping_source` records the route used; `match_lvl` only applies to the original WRDS link.

In this interval, SIVB, SBNY, and FRC have membership records that extend beyond their last active CRSP name record. The downloader preserves their membership and uses their last known historical ticker strictly as an identifier, flagged `last_known_inactive`. This does not assert active trading. Missing symbols or absent eligible trades remain missing OHLC rows, with zero eligible volume and trade count. No prices are forward-filled or synthesized. Active members without a validated symbol mapping cause a failure.

## Trade policy and limitations

This is a **conservative filtered-trade demo**, not an official consolidated OHLCV product:

- Raw source: `taqm_2023.ctm_YYYYMMDD`, using SIP timestamps and deterministic sequence tie-breaking.
- Session: [09:30:00,16:00:00) Eastern; prints at exactly 16:00 and later are excluded.
- Require positive price and size and correction code `00`.
- Accept only sale-condition strings composed of spaces, `@`, `E`, and `F` (regular trades, automatic execution, and intermarket sweep). NULL condition strings are excluded.
- Exclude odd lots, special opening/closing conditions, extended-hours, late, out-of-sequence, and other special conditions under this deliberately narrow whitelist.
- OHLC, VWAP, volume, and trade count all use the same eligible subset. **Volume is eligible filtered volume, not total reported market volume.**
- No quote-based outlier filtering or reconstruction of later cancellation/correction messages has been implemented. Screening correction flags alone is not full tape reconstruction.
- Prices are raw, unadjusted transaction prices. Corporate-action factors are stored separately; windows spanning actions need consistent adjustment before modeling. Do not substitute the CRSP daily volume for the intraday eligible volume.

The NYSE historical specification documents these condition codes: [Daily TAQ Client Specification v3.0b](https://www.nyse.com/publicdocs/nyse/data/Daily_TAQ_Client_Spec_v3.0b.pdf). The policy is explicit so a later research version can implement a broader, tape-specific price/volume eligibility policy and compare the results.

Before training, inspect missingness, outliers, corporate actions, membership changes, and consistency with independent daily references. The download does not establish tradability or strategy profitability.

## Validation

```bash
python -m unittest discover -s tests -v
python validate_intraday_demo.py
```

Checks include historical membership/mapping validation, unique security/time keys, OHLC ordering, preservation of missing intervals and inactive members, explicit timezone handling, restricted query identifiers, and conservative filter construction. Live download status is recorded in the data manifest; a pilot or partial manifest is not evidence that all six months have completed.
